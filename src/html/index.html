Source Guide / 数据源说明

English

Enable pages first, then configure only the data sources those pages need. Defaults are used when available; required fields are shown only for data that cannot be inferred safely.

  • Weather uses Open-Meteo by default. City, coordinates, and units can be changed; no API key is required.
  • Calendar pages require a direct ICS URL from Google, Outlook, Apple, or another calendar. Secrets are stored locally and only masked metadata is returned by GET APIs.
  • News has default RSS/Atom feeds: BBC, Hacker News, and NASA. Stock Watchlist defaults to Stooq CSV symbols such as AAPL.US, MSFT.US, and BTCUSD.
  • Economic Calendar requires a real RSS or ICS feed URL. Portfolio positions are user-owned sensitive data and are not echoed back by GET APIs.
  • World Clock and Focus Clock need no network source. Configure up to four city rows; empty rows are skipped.
  • Indoor Climate reads local sensor data when enabled. Leave disabled if the device has no sensor attached.

中文

先在 Pages 中启用页面，再配置该页面真正需要的数据源。能使用默认公开数据的模块会自动工作；无法安全推断的数据会标为必填。

  • 天气默认使用 Open-Meteo。城市、经纬度和单位可以修改，不需要 API Key。
  • 日历页面需要 Google、Outlook、Apple 或其他日历的直接 ICS URL。密钥只保存在设备本地，网页 GET 接口只返回脱敏信息。
  • 新闻默认使用 BBC、Hacker News、NASA 的 RSS/Atom；股票默认使用 Stooq CSV，例如 AAPL.US、MSFT.US、BTCUSD。
  • 经济日历需要真实 RSS 或 ICS Feed URL。投资组合是用户敏感数据，不会通过 GET 接口回显明文。
  • 世界时钟和专注时钟不依赖外部数据源。最多配置四个城市行，空行不会显示。
  • 室内环境依赖本地传感器；没有接入传感器时保持关闭即可。
